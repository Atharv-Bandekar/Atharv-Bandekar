## Academic Projects

<details>
<summary><b>ReviewGuard — E-Commerce Truth Detector</b></summary>
<br/>

A real-time fraud detector built to flag promotional spam and AI-generated reviews, combining a fine-tuned DeBERTa-v3 Small classifier with a custom O(N) heuristics engine, plus a Chrome Extension that explains predictions in plain language using LLaMA 3.1.

| Attribute | Detail |
|---|---|
| Stack | Python, TensorFlow, Flask, Hugging Face, Groq API (LLaMA 3.1), JavaScript (Manifest V3) |
| Dataset | 50,000 reviews |
| Result | 98% test accuracy, 0.98 F1-score |
| Notes | CPU-only inference to avoid GPU hosting costs |
| Outcome | Paper accepted and presented at COMPUTATIA 2026 |
| Repository | [View Repo](https://github.com/Atharv-Bandekar) |

Also engineered a Flask batch-prediction endpoint (`/predict_batch`) that scores reviews in chunks and streams results progressively, with the first batch returned in 5–10 seconds.

</details>

<details>
<summary><b>Network Security Threat Detection Pipeline</b></summary>
<br/>

An MLOps pipeline for phishing detection — training, tracking, and deploying an ensemble of classifiers as a containerized service.

| Attribute | Detail |
|---|---|
| Stack | Python, Scikit-Learn, FastAPI, MongoDB, MLflow, Docker, AWS S3 |
| Dataset | 11,000-record phishing dataset, 10-fold cross-validation |
| Result | Mean F1-score of 0.97 across 5 tuned classifiers |
| Notes | Containerized and deployed as a FastAPI service |
| Outcome | CSV batch predictions auto-synced to AWS S3 |
| Repository | [View Repo](https://github.com/Atharv-Bandekar) |

Trained and tuned Random Forest, Decision Tree, Gradient Boosting, Logistic Regression, and AdaBoost classifiers, with experiment tracking via MLflow/DagsHub and MongoDB-backed data ingestion.

</details>

<details>
<summary><b>CogniCare AI — Multi-Agent Mental Healthcare Assistant for the Elderly</b></summary>
<br/>

A full-stack, multilingual mental healthcare platform built for the AICTE | IBM SkillsBuild Internship, running a 3-agent pipeline (Interviewer, Evaluator, Coordinator).

| Attribute | Detail |
|---|---|
| Stack | Next.js, FastAPI, Python, Groq API (LLaMA, Whisper), Hugging Face (DeBERTa), Supabase (PostgreSQL) |
| Scope | 5 REST endpoints, 3-agent pipeline |
| Notes | Multilingual voice pipeline via Groq Whisper large-v3 |
| Outcome | Conversation history persisted in Supabase (PostgreSQL) |
| Languages | English, Hindi, Marathi, Tamil |
| Repository | [View Repo](https://github.com/Atharv-Bandekar) |

Built a multilingual voice pipeline combining Groq Whisper large-v3 transcription with a locally hosted DeBERTa evaluator, including script normalization for cross-lingual evaluation.

</details>
