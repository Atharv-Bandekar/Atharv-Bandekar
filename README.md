## 🚀 Featured Projects

<details>
<summary><b>🛡️ ReviewGuard — E-Commerce Truth Detector</b></summary>
<br/>

Real-time fraud detection system combining a fine-tuned DeBERTa-v3 Small classifier with a custom O(N) heuristics engine to flag promotional spam and AI-generated reviews at scale, paired with a Chrome Extension that explains predictions in plain language via LLaMA 3.1.

| Attribute | Detail |
|---|---|
| **Stack** | Python, TensorFlow, Flask, Hugging Face, Groq API (LLaMA 3.1), JavaScript (Manifest V3) |
| **Scale** | 50,000-review dataset |
| **Performance** | 98% test accuracy · 0.98 F1-score |
| **Security** | CPU-only inference, no user data persistence in extension |
| **Impact** | Published research paper at COMPUTATIA 2026 (Atlantis Press) |
| **Repository** | [View Repo](https://github.com/Atharv-Bandekar) |

Engineered a Flask batch-prediction endpoint (`/predict_batch`) that streams scored reviews progressively — first batch returned in 5–10 seconds — using CPU-only inference to eliminate GPU hosting costs while maintaining production-level throughput.

</details>

<details>
<summary><b>🔐 Network Security Threat Detection Pipeline</b></summary>

End-to-end MLOps pipeline that trains, tunes, tracks, and deploys an ensemble of classifiers for phishing detection, containerized for reproducible, cloud-synced inference.

| Attribute | Detail |
|---|---|

| **Scale** | 11,000-record phishing dataset, 10-fold cross-validation |
| **Performance** | Mean F1-score of 0.97 across 5 tuned classifiers |
| **Security** | Containerized deployment, isolated inference service |
| **Impact** | Automated CSV batch predictions auto-synced to AWS S3 |
| **Repository** | [View Repo](https://github.com/Atharv-Bandekar) |

Trained and tuned Random Forest, Decision Tree, Gradient Boosting, Logistic Regression, and AdaBoost classifiers, with full experiment tracking via MLflow/DagsHub and MongoDB-backed data ingestion, deployed as a containerized FastAPI service.

</details>
